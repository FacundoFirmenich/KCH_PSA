# KCH_PSA

**KCH Personal Super Assistant** es la reconstrucción limpia iniciada el 5 de noviembre de 2026 para consolidar KCH y Jarvis sobre evidencia actual, sin tratar automáticamente las ramas de agosto como estado vigente.

## Estado

- Repositorio nuevo e independiente.
- R33 permanece como antecedente nativo operativo que debe auditarse, no copiarse a ciegas.
- R34 está deprecada como release operativa y se conserva únicamente como objeto forense hasta localizar sus fallos de fluidez, interposición y arquitectura.
- El proyecto Jarvis y las ramas KCH posteriores deben reconciliarse desde sus fuentes actuales en Biblioteca/tareas, GitHub, Drive y artefactos locales.
- El kernel neutral de engines, el ciclo de vida durable y el supervisor host-real acotado están implementados; la suite local Windows/Python 3.14 pasa 30/30 tests.
- La genealogía remota KCH/Jarvis de agosto-septiembre está reconciliada por carriles; una versión mayor no transfiere autoridad por sí sola.
- No hay promoción, activación universal, entrenamiento PHL ni migración automática de claims históricos.
- Un testigo Windows host-real acotado pasó con identidad fuerte, lease finito, logs, ledger válido y terminalidad verificada; no equivale a daemon continuo ni producción.

## Misión inicial

1. Identificar las dos proyecciones nativas 0.11.33 y medir su comportamiento real.
2. Explicar causalmente por qué R34 no reprodujo la experiencia nativa de R33.
3. Investigar el ecosistema contemporáneo de arneses y agentes —incluidos OpenClaw, Cline, OpenCode, Qwen Code y LangGraph— usando fuentes oficiales actuales.
4. Recuperar el estado posterior de KCH y Jarvis sin fusionar genealogías ni transferir autoridad.
5. Diseñar una R34 genuinamente nativa y la arquitectura KCH_PSA sólo después de cerrar esos gates.

## Frontera de evidencia

Este README fija el punto de partida, no demuestra todavía integración, superioridad, despliegue ni causalidad. Los resultados adversos y las releases deprecadas se preservarán como evidencia, no como autoridad operativa.
